# Analyses multivariées

Choisis la méthode selon le tableau : ACP pour des variables quantitatives, AFC pour un tableau de contingence, ACM pour des variables qualitatives. Retire identifiants, totaux, constantes et colonnes de masse nulle. Traite les `NA` explicitement. Sépare variables actives et supplémentaires. Justifie le centrage-réduction, le nombre d'axes et l'interprétation par inertie, contributions et cos². Pour une typologie, fixe la graine, documente les axes et le nombre de groupes, puis décris les classes dans les variables d'origine.
